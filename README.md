# Clean Genie Cleaning Co - Customer Frontend

**Clean Genie** is a responsive web-based booking system for scheduling professional cleaning services. This repository contains the user-facing frontend, designed to provide a seamless booking experience.

## ✨ Features
*   **Service Landing Page:** Highlights company trust, quality, and satisfaction guarantees.
*   **Interactive Booking Form:** Collects customer details, address, and service preferences.
*   **Instant Cost Estimator:** Calculates estimated pricing dynamically based on floor area and chosen service.

## 🛠️ Tech Stack
*   **HTML5** - Semantic structure
*   **CSS3** - Styling and responsive layout
*   **JavaScript** - Interactivity and API integration
